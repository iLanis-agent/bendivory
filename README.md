# Bendivory 1.0 TEST
Native Java/Canvas Android 8+ Mochinyoro rectangle-network puzzle.

Shade unnumbered cells so every edge-connected white group is a filled rectangle. All white rectangles must form one network through corner contacts. Each white rectangle has at most one clue, whose number gives its area; unclued rectangles are allowed. Clues stay white. No dark 2x2 is allowed, and every edge-connected dark group must be nonrectangular, including no singleton or straight bar. Twelve distinct 4x4 clue boards have twelve distinct unique solutions; each solution includes an unclued white rectangle.

Saved rectangle palette and cell guides, GG007 icon/menu/site/privacy, unlimited undo/reset. Offline, no ads, analytics, account or requested permissions. Settings and completed-puzzle marks stay on device. External studio link opens browser.

Independent Java coordinate-set components, pairwise rectangle-fill checks and a white-rectangle corner graph agree with production bitset floods, bounding-box areas and king-neighbor connectivity on all 65536 masks per board. Exactly one solution per board; fixed clues, bounds, solve, undo and replay pass. Adapter navigation, saved settings, privacy, cell taps, next, levels and persistence pass. Actual drawing pixels inspected, not phone screenshots. Phone runtime, performance and browser handoff QA incomplete. Signed TEST only, not final or Play published.

Current 803-entry registry, 127 partial recovered README records and exact Dominoreef cumulative stage found no Mochinyoro match. Shares Ivoryfen/Mochikoro white-rectangle corner-network and no-dark-2x2 backbone, but adds nonrectangular dark-component exclusion and permits unclued white rectangles. This changes legal masks and the solver; unlike Ivoryfen every dark component must bend and not fill its bounding box. Unlike Cornerfen/Scrin there is no degree-two rectangle corner cycle. Usowan was rejected as Hushgrove/Usoone under another name; Yajikazu was rejected as existing Yajisan-Kazusan. Known Mochinyoro genre variant, not a global invention. Partial corpus, not ALL-local. Rules https://ericfox53.blogspot.com/2021/02/196-mochinyoro.html and the English rules at https://www.janko.at/Raetsel/Mochinyoro/index.htm . The latter page has conflicting Japanese text; implemented rules follow the agreeing English sources.
